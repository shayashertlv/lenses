THESIS: Every complaint traces to one architectural gap: face-space constants (bridge pin, nose shape, standoff, resting height) are re-derived per frame from single-frame measurements, so per-frame noise and per-pose systematic error both reach the screen — worst exactly at hard poses, where the inert r2 gate trusts MediaPipe z fully and the binary measuring gate abandons personalisation entirely. The design assigns every quantity to its honest timescale: (T0) frame-locked and raw — the pose measurement, ray x/y pinning, the composite (untouched); (T1) 30–300 ms — the pose filters (conditioned, not retuned: signed rotation rate + noise-floor subtraction so noise stops opening the cutoff), the bridge-pin innovation (One Euro in face space, zero screen lag because the pose carries it), the view-locked deform residual (SHAPE_TAU, now with a noise-floor shrinkage so a still head is genuinely at rest), and a 0.3 s EMA on the depth-fit weight; (T2) seconds-to-minutes — a per-vertex anisotropic recursive estimator (the person model) that fuses ray-pinned observations across poses, converting yaw parallax into prior-free nose depth (A_zz literally accumulates sin²(view angle) — the parallax IS the confidence), plus the seat's resting height/standoff solved as face constants on shape-commit events; (T3) events — identity reset, remeasure. Filtering only ever touches face-space constants or the noise DC of the activity signal, never the level path of the pose or the per-frame image pinning, so the 29.5→3.8 mm sweep-lag win survives by construction and is re-asserted by the harness. Binary regimes (measuring latch payload, hard max() argmax, drift-triggered rebuilds) are replaced by continuous weights, soft-max, and effect deadbands, so there is no boundary left to step across. Jitter is budgeted per path to ≤0.3 px RMS frontal / ≤0.6 px at 35° yaw and each stage lands with a harness check that measures its own claim, with the user's own diag/f00-f09 captures as the replay regression set. Workstreams A and B are deliberately minimal: A is one new module layered under the existing view-locked deform (frame one is bit-identical to today), B is a reduction change over data the field already contains (width-at-height is a derived query, not a new measurement).

=== PERSON MODEL ===
## A. PERSON MODEL — ar/src/person.js (new), consumed by frame.js, occluder.js, anchors.js

### Purpose
Turn rigidity-over-time into convergence: the bridge pin (6.8 mm cross-pose wander), the nose shape, and depth (currently MediaPipe-z-prior via the inert r2 gate) become slowly-converging face-space constants with per-vertex confidence, layered UNDER the existing view-locked deform so the mesh still covers THIS image every frame.

### Data model (exact fields)
createPersonModel(face) returns `person` held on `state.person`:
- `A`: Float32Array(468*6) — per-vertex symmetric 3x3 information matrix (xx,xy,xz,yy,yz,zz), face-space cm units.
- `b`: Float32Array(468*3) — information vector.
- `W`: Float32Array(468) — accumulated scalar weight (unit = one full-trust frontal frame).
- `est`: Float32Array(468*3) — committed estimate x̂_i (face-space positions; init = face.positions copy).
- `offsets`: Float32Array(468*3) — x̂_i − rest_i, clamped ±OFFSET_LIMIT (2.0 cm), what the occluder layers on.
- `zConf`: Float32Array(468) — A_zz,i − PRIOR_LAMBDA (the parallax accumulator, see below).
- `resNoise`: Float32Array(468) — EMA (tau 2 s) of |transverse innovation|, per-landmark online noise estimate (init 0.05 cm).
- scalars: `frames`, `resets`, `residualRms` (robust median transverse residual over vertices with W>10), `tripwireSeconds`.
Memory: ~25 KB. Per-frame cost: one O(468) pass of ~20 mul/vertex — well inside budget 5.

### Per-frame update law (called from measureShape, which already has everything needed)
Inputs per vertex i (all already computed in occluder.js measureShape): p_i = observed carried point (the `observed` array from carryLandmarks); d_i = normalize(p_i − cameraInFace) (ray direction in face space; cameraInFace exists at occluder.js:765); v_i = the facing×visibility trust (the `facing` variable at occluder.js:799-807 — currently used once and dropped; export it per-vertex into a scratch Float32Array); w_pose = continuous pose trust from workstream C.

1. Weight: w_i = w_pose · v_i · s_i, with stability s_i = 1/(1 + (resNoise_i/0.05)²) (nose tip, measured 2-6x noisier, self-downweights).
2. Robust gate (Huber on the transverse residual — the only well-measured component): r = p_i − est_i; r_t = r − (r·d_i)d_i; if |r_t| > 3·max(0.1 cm, resNoise_i): w_i *= 3·max(0.1, resNoise_i)/|r_t|. Update resNoise_i += α₂(|r_t| − resNoise_i), α₂ from tau 2 s, only when w_i > 0.2.
3. Anisotropic information update (the parallax math): M_i = w_i·(I − (1 − W_PAR)·d_i d_iᵀ) with W_PAR = 0.01 = σ²_transverse/σ²_along-ray = (0.5 mm/5 mm)². A_i += M_i; b_i += M_i·p_i; W_i += w_i.
   Why this recovers depth without the z prior: transverse to the ray the observation is a true measurement (ray pinning); along the ray it is the borrowed/fitted guess, weighted 100x down. As the head yaws, d_i rotates in face space, so transverse planes from different poses intersect — A_zz,i ≈ Σ w_i(W_PAR + (1−W_PAR)sin²θ_i) accumulates exactly the triangulation information. Depth converges from parallax across the user's own ±10-18° browsing; MediaPipe z never enters except through the frame-one prior.
4. Forgetting cap: if W_i > W_MAX (300): scale A_i, b_i, W_i by W_MAX/W_i → converged vertices become an exponential window with adaptation tau ≈ W_MAX/w̄ ≈ 20-60 s (slow drift, glasses-removal marks, lighting bias all heal).

### Commit (event cadence, ≤ COMMIT_HZ = 2 Hz, scheduled on the surface-rebuild tick)
x̂_i = (A_i + λI)⁻¹(b_i + λ·rest_i) — closed-form symmetric 3x3 solve, λ = PRIOR_LAMBDA = 4 (four full-trust frames of canonical prior; conditions the solve and makes frame one exact). offsets_i = clamp(x̂_i − rest_i, ±OFFSET_LIMIT). zConf_i = A_zz,i − λ·(row weight).
Commit re-basing (makes commits invisible — no step, no rebuild): after updating person.offsets, occluder viewResidual_i −= Δoffsets_i, so skinOffset (below) is continuous across the commit.

### Layering with the view-locked deform (occluder.js measureShape — the single-surface invariant is untouched)
The drawn/seat surface offset becomes a sum: skinOffset_i = person.offsets_i + viewResidual_i. measureShape's loop changes from easing `offsets` toward target to easing `viewResidual`:
  target_i = clamp(p_i − rest_i, ±OFFSET_LIMIT)  (unchanged)
  e_i = target_i − (person.offsets_i + viewResidual_i)
  ẽ_i = e_i · max(0, 1 − r0_i/|e_i|)  — vector shrinkage with r0_i = max(SHRINK_FLOOR=0.03 cm, 1.5·resNoise_i)
  viewResidual_i += (1 − exp(−dt/SHAPE_TAU)) · facing_i · ẽ_i  (same alpha law, same facing×visibility gains, same first-sample-adopted-whole rule via hasShape)
The shrinkage is the rebuild-cadence fix at the source: on a still head, innovations sit inside the noise floor, viewResidual stops moving, drift stops accumulating, and the surface genuinely rests (target: rebuilds ≤10/60 vs measured 39-62/60). On real motion/expression |e| exceeds r0 and passes with ≤SHAPE_TAU lag exactly as today — the mesh covers this image every frame. Bounded residual error from shrinkage: ≤0.3 mm, under the seat's own precision.

### Frame-one equality (hard constraint 2)
Empty model: A=0, b=0 → x̂ = rest → person.offsets = 0 → skinOffset = viewResidual, first sample adopted whole — bit-identical to today's path. The pin filter (workstream C) adopts its first sample whole. No prompts, no phases; convergence is silent accumulation during natural use. Face loss never resets it (only the pose filter resets, as today).

### Replacing the inert r2 gate for bridge/nose depth (the math)
Interim (cold session): fitLandmarkDepth keeps the camera-derived slope (keep-list) but gains (a) nose-region residual in the SAME loop — a second set of running sums over the precomputed 98-vertex nose mask, r2_nose and rmsNose computed against the rotation-detrended (per-region de-meaned) residual after the affine — and (b) temporal conditioning (workstream C): weight = smoothstep(EMA₀.₃ₛ(r2)) · smoothstep_down(rmsNose over [0.15, 0.30] cm); b and a also EMA'd at 0.3 s. This makes the gate informative (rmsNose rises when the far sidewall hallucinates even while global r2 inflates) and un-ditherable.
Mature (per-vertex, prior-free): once zConf_i ≥ Z_CONF_MIN = 25 (transverse-weighted samples → σ_z ≈ 0.5 mm/√25 ≈ 0.1 mm; reachable in ~15-25 s of ±10-18° browsing since 25/sin²(15°) ≈ 370 weighted frames), the borrowed depth in carryLandmarks/measureAnchors for that vertex crossfades to the person surface depth: depth_i = borrowed + (personCameraDepth_i − borrowed)·clamp(zConf_i/Z_CONF_MIN, 0, 1), eased 0.5 s at the crossfade onset. The bridge pin (vertex 6) is the first beneficiary: its depth stops depending on the depth fit entirely — this kills the 5.0 mm cross-pose z wander and the r2-band exposure at the one point everything hangs from.

### Bridge pin fusion (consumed by frame.js — see noiseConditioning for the filter)
p_fused = est[LM.NOSE_BRIDGE]; maturity κ = clamp(W_6/W_PIN_FULL=60, 0, 1). Per-frame pin p_pin = p_fused + OneEuro_faceSpace(p_obs.bridge − p_fused), where the One Euro's activity input is the pose's measured speed (transparent during real motion, closed at rest). Placement principle honoured: x/y still come from THIS frame's landmark through the innovation term; only the noise floor and the pose-systematic DC are removed. occluder translation uses the same conditioned anchors.bridge, so frame and occlusion boundary stay welded (occluder.js:717-731 unchanged in structure).

### Identity change and resets
- isDifferentFace (frame.js:549, unchanged thresholds) → person.reset() (A,b,W,zConf,resNoise cleared; est=rest) alongside resetFit. Evaluated only when w_pose > 0.5.
- remeasure() and the Adapt-to-face toggle-off → person.reset() (parallel to the occluder's own shape reset at occluder.js:697-707).
- Soft tripwire (glasses put on, hairstyle change — same person): if residualRms > 0.25 cm sustained > 1 s, decay A,b,W by 0.9/frame until it recovers — self-healing without a visible reset.

=== SEAT SOLVE ===
## B. SEAT EQUILIBRIUM — ar/src/nose.js + fit.js + frame.js

### DOFs and their timescales
- s — standoff along face +Z (bridge-relative, as today; the field is parameterised in face z and seat()'s bridge-error cancellation — verified algebraically in the diagnosis — depends on this frame; the sub-mm camera-axis coupling of empirics seat-cause-4 is accepted and measured, not solved). Per-frame evaluation, event-scale target, SEAT_TAU ease + effect deadband.
- u — resting height along bridgeUp, relative to the optical (pupil) height. A face×frame constant. Solved on shape-commit events only, eased at REST_TAU = 0.8 s through REST_DEADBAND = 0.3 mm. This is what makes the frame hang where THIS nose carries it (the 1.9 mm-height-per-mm-of-DBL-mismatch law).
- ψ — optional pad-balance rotation about bridgeUp (differential pad depth is balanced by rotation about the vertical axis; pure roll about Z balances differential pad height — both expressible, both OFF by default behind fit.padBalance, capped ±2°, eased 0.5 s, enabled only when person nose confidence is high). Stability-first: ships dark in stage 5, enabled after live validation.
- Pantoscopic tilt stays the rake-conditioned constant (fit.js:430-434); pitch is reported, not solved.

### Load-time pad statistics (fit.js analyseModel, after findBridgeSurface)
Split noseContacts by side: R = {c.x < centre.x − 0.15·(size.x·BRIDGE_COLUMN)}, L mirror; centre band = saddle set. Per side: mean bearing point m_side over the rearmost-per-bin points in the pad band (y within [contactY − 1.2, contactY + 0.4] cm scaled). Exports on the model: padSepM = m_L.x − m_R.x (metres), padPlane = {y: mean y, z: mean z} (model space), hasPads = both sides ≥ 8 samples. Harness already asserts spread across centreline (pipeline-check.js:507-526) — this formalises it.

### Wedge queries on the existing field (nose.js, pure derived reductions — no new data)
- sidewallXAt(y, z, side): march x from 0.3 cm outward in CELL (1 mm) steps; return the first crossing where depthAt(side·x, y) < z, linearly interpolated between the bracketing cells; NaN if no crossing before the window edge or any NaN cell.
- noseWidthAt(y, z) = sidewallXAt(y,z,+1) + sidewallXAt(y,z,−1); NaN-propagating.
- normalAt(x, y) = normalize(−∂D/∂x, −∂D/∂y, 1) by central differences over ±1 cell (used for contact classification and the ψ balance; ridge vs sidewall: |n_x| > 0.5 ⇒ sidewall).
- ridgeZAt(y) = max over x∈[−0.3, 0.3] of depthAt(x, y).
All queries operate in field coordinates; callers convert via the same origin/bridge shift seat() uses, preserving the exact bridge-error cancellation.

### The resting-height solve (event cadence — on person/shape commit, fit change, or model swap; ≤2 Hz; ~37×810 lookups ≈ 1 ms)
Given the current scale, quaternion, and optical placement (through fit.js's vertical stage), for u on a grid [−1.2, +0.6] cm along bridgeUp, step 0.5 mm:
1. Place the pad plane: y_pad(u) = field-space y of the model padPlane after hang + slide by u; z_pad(u) = ridgeZAt(y_saddle(u)) − PAD_SINK + (padPlane.z − contact z)·scale — the pad-plane depth when the centreline contact is seated at the ridge (decouples the height search from s).
2. Wedge mismatch: q(u) = padSepCm − noseWidthAt(y_pad(u), z_pad(u)). q decreases with descent (nose widens downward at ~0.54 mm width/mm height — canonical measurement).
3. Root: u* = the sign crossing of q, sub-grid interpolated. Physiological check: local slope |dq/du| ∈ [0.2, 1.2] mm/mm, else degenerate.
4. Pupil soft cost (demoting the optical target from constraint to preference): u_rest = (1 − LAMBDA_PUPIL)·u* + LAMBDA_PUPIL·0, LAMBDA_PUPIL = 0.25, then clamp ±maxPupilCorrection. pupilHeightInLens (fit.js:539) is reported as the fit VERDICT — "this frame sits low on you" is a feature.
5. Confidence scaling: multiply (u_rest − current) by clamp(meanNoseW/50, 0, 1) — a cold or gate-starved session stays at today's optical height and converges as the person model does.
Degenerate cases: no crossing (flat/very wide nose), >40% NaN pad rows (occluded sidewalls), slope out of band, hasPads false → u_rest decays to 0 (today's behaviour is the floor, never a cliff — the ease and deadband make the fallback invisible).

### Per-frame work (unchanged shape, conditioned reductions)
seat() keeps its exact bridge-relative formulation and contact loop, with two changes:
1. Soft-max: worst = I_max + τ_s·ln(Σ_{c: I_c > I_max − 2τ_s} exp((I_c − I_max)/τ_s)), τ_s = SOFTMAX_TEMP = 0.3 mm. Argmax flips between contacts within ~0.3 mm become continuous; bias (+0.1–0.3 mm) is constant-like and absorbed by a one-time PAD_SINK recalibration check against the catalogue.
2. Per-side reporting: the same loop accumulates soft-max per side → result.perSide = {IL, IR, gap: |IL − IR|}, plus restedSide and the contact's normalAt classification. Nothing else solves per frame.
In frame.js, the SEAT_TAU ease gains an effect deadband: the ease target only re-arms when |rawPush − currentTarget| > 0.15 mm (release at 0.05 mm) — at 1.74 px/mm that is 0.026 px, invisible, and above the measured 0.02–0.08 mm noise, so the seat literally rests between real changes. Reset-on-remeasure preserved.

### Integration point in solvePlacement (staged order preserved: no stage undoes an earlier one)
solvePlacement({model, anchors, fit, face, surface, seatPlan}) with seatPlan = {heightAlongBridge: eased u_rest (cm, default 0), balanceYaw: eased ψ (rad, default 0)} — computed and owned by frame.js state, a slowly-varying INPUT, not an in-pass iteration:
scale → orientation (quaternion pre-multiplied by AxisAngle(bridgeUp, ψ)) → position (hang on conditioned bridge) → vertical (existing pupil slide + seatPlan.heightAlongBridge/max(up.y, 0.2) along bridgeUp) → seat (soft-max s) → offsetZ. The 'z cannot undo earlier stages' comment (fit.js:497-501) stays true: height is now informed by the wedge but still settled before s.

### Stability under field noise
Three independent defences, by timescale: (1) the field itself stops moving on a still head (workstream A shrinkage — the diagnosis showed field morph is the WHOLE seat-noise driver at hard poses); (2) the event solve touches u_rest at ≤2 Hz through a 0.3 mm deadband and a 0.8 s ease — a face constant filtered in face space, zero pose lag; (3) the per-frame s passes soft-max (no argmax steps) then the effect deadband then SEAT_TAU. Gate-flip regime swaps are gone because the gate is gone (workstream C): there is no measured-vs-canonical seat regime left to step between (the measured 2.2 mm step ceases to exist as a category).

=== NOISE CONDITIONING ===
## C. NOISE CONDITIONING — smoothing.js, frame.js, anchors.js, occluder.js, main.js

### The jitter budget (px RMS of the placed-frame origin, 960 px buffer, 45 cm, 1.74 px/mm; targets ≤0.3 frontal / ≤0.6 at 35° yaw on a still head)
Frontal: pose-position residual 0.10 + pose-rotation residual 0.08 + bridge pin 0.10 + eyeLine/bridgeUp path 0.00 (always-carried) + seat/occluder breathing 0.03 → RSS ≈ 0.17 px (1.8x margin). At 35° yaw: rotation 0.28 + position 0.25 + pin 0.25 + depth-weight 0.05 (EMA'd) + regime steps 0.00 (removed) → RSS ≈ 0.45 px. Margin held because the diag noise injection is 2-4x below a real webcam; the diag-replay harness asserts the budget at 2x injected noise.

### C1. Rotation signed-rate fix (smoothing.js PredictedRotation.update, ~8 lines)
Replace the scalar `rate` LowPass on |stepAxis|/dt (rectified BEFORE smoothing, smoothing.js:466-471) with a Vector3 LowPass on the SIGNED per-axis components stepAxis/dt at dCutoff; measuredRate = smoothedVector.length() (magnitude AFTER smoothing — the position path's treatment). Alternating-sign noise now cancels instead of reading as a DC turn rate. Measured what-if (shipped-law sim): at σ0.015 rad/frame cutoff 9.32 → 3.32 Hz, transmission 0.73 → 0.64; sweep-lag cost 0.0110 → 0.0122 rad on a 20° 0.5 Hz sweep — responsiveness unchanged. Constants untouched.

### C2. Noise-floor subtraction (both filters; new NoiseFloor helper in smoothing.js)
Estimator: per filter, a 32-sample ring (~1.07 s @30 fps) of the post-dCutoff smoothed rate; n̂ = its 25th percentile (insertion into a small sorted copy per frame — 32 elements, negligible; robust: still moments dominate the low quantile even during motion bursts). Subtraction: activityEff = max(0, measuredSpeed − n̂), fed to beta ONLY — the level update, minCutoff, and the lag ceilings are untouched, so slow real motion (below the floor) still tracks through the 0.6/0.7 Hz minimum cutoff with its ordinary ≤0.26 s settle, and the floor cannot gate position. Lag proof: real head speeds (10-25 cm/s, 0.5-3 rad/s) sit 5-20x above the floor (~1-5 cm/s, 0.02-0.09 rad/s post-C1); at the sweep's 25 cm/s peak, subtracting ≤5 cm/s moves the cutoff 30.6 → 24.6 Hz = τ 5.2 → 6.5 ms ≈ +0.3 mm on a 25 cm/s sweep. Harness pins total sweep lag ≤ 5 mm (baseline 3.8 mm) and slow-ramp (2 cm/s) tracking ≤ 1 mm.

### C3. Bridge-pin conditioning in face space (frame.js + person model)
p_pin = p_fused + OneEuroVector3(p_obs.bridge − p_fused), settings {minCutoff 0.8 Hz, beta 3.0, dCutoff 3.0}, with the activity input = the pose smoother's measuredSpeed mapped to the nose lever (|v| + 8·|ω| cm/s, from smoother.position.measuredSpeed and rotation rate) and C2's floor subtracted. Why zero pose lag: screen position = smoothed pose ∘ face-space pin; on a rigid head the pin is constant in face space, so filtering it adds NO lag to head motion by construction — the pose carries it. What the innovation term carries is landmark slide (pose-correlated systematic — passed when the pose moves because beta reads pose speed, exactly when it is invisible) and noise (killed at rest by the 0.8 Hz floor: τ ≈ 0.2 s on a face-space constant, transmission ~0.25 → pin contribution 0.35 px → ~0.1 px). First sample adopted whole (frame-one identity). Applied to anchors.bridge BEFORE updateOccluder and solvePlacement, so the frame, the occluder translation, and seat's shiftZ all ride the same conditioned pin — the weld is structural. eyeCentreX gets the same treatment (shares the filter class).

### C4. Continuous pose-trust replacing the binary measuring gate (frame.js)
w_pose = wy·wp·wr, all from the TRUE pose euler (poseEuler YXZ, frame.js:249 — already computed; estimateYaw's image asymmetry, which conflates pillow roll and closed the gate on 5/10 of the user's captures, is demoted to a readout): wy = 1 − smoothstep(0.17, 0.45, |yaw|); wp = 1 − smoothstep(0.20, 0.45, |pitch|); wr = 1 − smoothstep(0.25, 0.60, |roll|). Ramp starts sit at today's effective admit thresholds (0.157 rad true yaw ≈ the 0.25 image gate) so frontal behaviour is unchanged; the tails reopen personalisation in the pillow regime with honest downweighting.
The 31-sample window: samples admitted whenever w_pose > 0.05, tagged with w_pose; medianAnchors becomes a weighted median (sort per field, take the value at cumulative weight ≥ half of total) — same robustness, no cliff. FIT_WINDOW stays 31; commitFit deadbands unchanged, plus FIT_DEADBAND.eyeLineY = 0.02 cm so the eye line rests like the widths do.
The latch and its binary payload are DELETED: eyeLineY, bridgeUp, ears.y/z are ALWAYS the carried (weighted-median, deadbanded) values — the diagnosis's own recommendation; the median is the better per-frame value even head-on, and there is no crossing left to step (removes the ~2.2 mm seat step + arm twitch per flip). bridge and eyeCentreX stay live (conditioned per C3) — the placement principle intact. isDifferentFace evaluated only when w_pose > 0.5. state.measuringLatch survives as a readout alias (w_pose > 0.5) for UI compatibility.

### C5. Recovery-dt fix (main.js, ~6 lines)
Track lastAppliedDetectionMs (set whenever updatePose consumes a detection). On the first detection after any faceless hold, pass dt = (nowMs − lastAppliedDetectionMs)/1000 instead of frame.captureDt (which understates 2-4x after HOLD_FACELESS_RESULTS rides a burst, blowing the cutoff open and landing the accumulated displacement as a snap). The filters already handle variable dt. The existing LOST_SECONDS_BEFORE_RESET path is unchanged (full reset still wins past 0.5 s).

### C6. Rebuild-cadence fix (occluder.js)
Primary: the workstream-A shrinkage floor stops still-head drift at the source. Backstop: rebuild trigger becomes driftSurface ≥ SURFACE_DEADBAND AND (framesSinceRebuild ≥ 3 OR driftSurface ≥ 0.1 cm) — a deadband on effect cadence, not accumulated micro-drift. Target measured on the diag stills: ≤ 10 rebuilds/60 frames (from 39-62/60), eased-push sd → 0 between real changes (the effect deadband in B holds the rest).

### C7. Depth-fit temporal conditioning (survives design A as the cold-session path; occluder.js fitLandmarkDepth + data.depthFit)
data.depthFit becomes persistent state (it already survives frames, overwritten memorylessly — the natural home): r2_s, b_s, a_s each EMA'd at DEPTH_EMA_TAU = 0.3 s (slow global quantities; a is rebuilt from raw |e[14]| per frame and jitters with pose z). weight = smoothstep(r2_s over [0.88, 0.92]) · (1 − smoothstep(0.15, 0.30, rmsNose_s)) where rmsNose is the nose-window (98-vertex mask, precomputed from canonical positions) RMS residual after the affine, de-meaned per region, accumulated in the SAME loop (free). The 0.04-wide band stops being a dither trap (37.5 slope × EMA'd input) and becomes informative (rmsNose sees far-sidewall hallucination that global r2 — measured RISING with pose severity, weight pinned 1.0/sd 0 on all 12 stills — cannot). As zConf matures (workstream A), per-vertex crossfade retires this path for converged vertices; it remains frame-one and cold-session behaviour.

### Timescale ledger (the design's spine)
T0 raw/frame-locked: pose measurement, ray x/y pinning, composite, lead 0 — untouched. T1 fast: pose filters (τ_rest ~0.15 s, self-opening on real speed), pin innovation (0.2 s), viewResidual (SHAPE_TAU 0.1 s), depth-fit EMA (0.3 s), SEAT_TAU (0.15 s). T2 slow face constants: person model (10-60 s), u_rest (0.8 s ease, 2 Hz solve), weighted-median window (~1 s). T3 events: identity reset, remeasure, model swap. Rule enforced by review: nothing at T1+ may sit on the screen-position path of a MOVING quantity; everything filtered is a face-space constant or an activity signal's noise DC.

=== RISKS ===
  - Noise-floor subtraction masks very slow real motion or adapts upward during sustained movement, adding lag on gentle sweeps -> Floor only ever subtracts from the beta activity — minCutoff still tracks all motion with ≤0.26 s settle and the lag ceilings are untouched; 25th-percentile estimator is dominated by still moments; harness pins slow-ramp (2 cm/s ≤1 mm) and the 0.5 Hz sweep (≤5 mm vs 3.8 baseline) so any regression is a red check, not a vibe
  - Person model converges to a biased shape from a systematically bad regime (all pillow poses, hallucination leakage) and then resists correction -> Pose-trust × facing × visibility × Huber gating bounds what enters; W_MAX forgetting bounds adaptation tau at 20-60 s; the residual tripwire soft-decays on sustained disagreement; isDifferentFace hard-resets; __ar.person.residualRms makes bias observable live; the synthetic-convergence check asserts monotonicity
  - Soft-max bias and the wedge height change perceived standoff/height on the existing catalogue — a regression dressed as a feature -> Stage-5 assertions include ≤0.3 mm standoff delta on the canonical face with padBalance off and the resting-height fallback (u_rest→0) on degenerate wedges, so today's behaviour is the floor; PAD_SINK recalibrated once against the baseline snapshot
  - Rest-height solve wanders on noisy/degenerate fields (flat noses, occluded sidewalls, cold sessions) and re-introduces breathing at a slower timescale -> Event cadence (≤2 Hz) + 0.3 mm deadband + 0.8 s ease + confidence scaling by person-model maturity + explicit degeneracy fallbacks (NaN fraction, slope band, no crossing → optical height); seat-stability measurable runs at the diag pillow pose specifically
  - Weighted admission of moderate poses biases the width/eyeLine medians that were previously frontal-only -> Weights derive from true pose euler (the failure mode was image-asymmetry conflating roll); weighted median is still a median (one tail cannot drag it); commitFit deadbands unchanged; diag-replay asserts measured widths land in the plausible band on all stills
  - Pin conditioning introduces a perceptible weld or expression lag (bridge innovation lagging a moving mouth/brow) -> Innovation filter is beta-driven by pose speed (transparent in motion), τ_rest only 0.2 s on a face-space near-constant; occluder translates on the identical conditioned pin so frame/boundary cannot separate (asserted bit-exact); scripted moving-head check pins pin-vs-truth ≤0.3 px
  - Latch deletion changes long-standing harness semantics and UI readouts -> measuringLatch kept as a derived readout (w_pose > 0.5); stage 2 updates only the checks that legitimately encode the latch, each with a comment tying it to the diagnosis finding it retires
  - Recovery-dt fix interacts with LOST_SECONDS_BEFORE_RESET or double-counts hold time -> dt override applies only to the first applied detection after a hold and is clamped to LOST_SECONDS_BEFORE_RESET; past that the existing full filter reset wins unchanged; recovery scenario in the harness covers both branches
  - Per-frame budget creep (person accumulate + soft-max + queries) on low-end 30 fps devices -> All per-frame additions are O(468) or O(existing contact loop) — measured ≈0.1-0.2 ms; event work (commit, rest-height) amortised at ≤2 Hz; __ar gains a frame-cost readout and the harness bounds updateFrame wall time vs baseline +10%
  - Two features interacting badly across stages (e.g., shrinkage floor starves the person model of innovation) -> Accumulation reads the RAW observed points (pre-shrinkage) — shrinkage only touches the render-path viewResidual; stage ordering puts each mechanism behind its own green harness before the next lands, and diag-replay A/Bs every stage against the pinned baseline
